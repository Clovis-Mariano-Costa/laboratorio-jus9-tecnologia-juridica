# Padrão Olá Mundo para Estudantes — Laboratório Jus 9

**Classificação:** PÚBLICO / LABORATÓRIO / ESTUDANTES / ORIENTAÇÃO  
**Projeto:** Laboratório Jus 9 Tecnologia Jurídica  
**Versão:** 2026-05-24

---

## 1. Objetivo

Todo estudante/acadêmico do Laboratório Jus 9 Tecnologia Jurídica deve começar com uma publicação simples e autoral:

> **Olá, Mundo.**

O “Olá, Mundo” marca o início da jornada de aprendizagem, autoria, organização e publicação responsável.

---

## 2. Local padrão

Cada estudante deve ter uma pasta própria:

```txt
ESTUDANTES/<nome-normalizado>/
```

E seu primeiro projeto deve ficar em:

```txt
ESTUDANTES/<nome-normalizado>/ola-mundo/
```

Exemplo:

```txt
ESTUDANTES/natan-menegaz-de-oliveira/ola-mundo/
```

---

## 3. Estrutura sugerida

```txt
ESTUDANTES/<nome-normalizado>/
├── README.md
├── ola-mundo/
│   ├── README.md
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── REGISTRO_DE_APRENDIZADO.md
└── projetos/
```

A estrutura pode ser simplificada quando o estudante já tiver publicado o projeto em outro repositório ou GitHub Pages. Nesse caso, o Laboratório pode manter uma página de registro com link para a publicação original.

---

## 4. Conteúdo mínimo do Olá Mundo

A primeira publicação deve conter, no mínimo:

- título “Olá, Mundo”;
- nome público do estudante, se autorizado;
- frase simples sobre o início da aprendizagem;
- link de volta para o Laboratório Jus 9;
- aviso para não inserir dados sensíveis.

## 6. Cuidados obrigatórios

Não publicar:

- CPF;
- RG;
- telefone pessoal;
- endereço residencial;
- dados de terceiros;
- documentos sigilosos;
- senhas;
- chaves;
- tokens;
- `.env`;
- qualquer dado sensível.

O Laboratório é público e educativo. Dados reais de estudante, autenticação, avaliação, histórico privado ou material sensível devem depender de backend, controle de acesso, logs, revisão humana e armazenamento privado.
