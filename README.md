## Aviso

Este repositório contém estrutura e modelos públicos de aprendizagem. Pastas secretas reais de estudantes não devem guardar dados privados no GitHub público.

Acesso real a dados privados, avaliação, histórico individual, autenticação ou área restrita dependerá de backend, controle de acesso, logs, revisão humana e armazenamento privado.

## Cuidados obrigatórios

Não publicar CPF, RG, telefone pessoal, endereço residencial, dados de terceiros, documentos sigilosos, senhas, chaves, tokens, `.env` ou qualquer dado sensível.
