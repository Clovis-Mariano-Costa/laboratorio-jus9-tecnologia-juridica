# Estudantes — Laboratório Jus 9

Área pública de estudantes, acadêmicos, aulas e primeiros projetos do Laboratório Jus 9 Tecnologia Jurídica.

## Primeira missão

Cada estudante deve começar com uma publicação simples e autoral:

> **Olá, Mundo.**

O objetivo é marcar o início da jornada de aprendizagem, registrar autoria, praticar HTML/CSS/JavaScript quando cabível e aprender a publicar com cuidado.

## Local padrão

```txt
ESTUDANTES/<nome-normalizado>/ola-mundo/
```

Não publicar CPF, RG, telefone pessoal, endereço residencial, documentos sigilosos, dados de terceiros, senhas, chaves, tokens ou qualquer dado sensível.
