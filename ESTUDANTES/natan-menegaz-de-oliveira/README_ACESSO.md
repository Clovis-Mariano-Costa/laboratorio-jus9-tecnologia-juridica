# Área de estudante — Natã Menegaz de Oliveira

**Classificação:** SIGILOSO / área educacional protegida.

Esta pasta é modelo de organização para projetos de estudante no Laboratório da Jus 9 Tecnologia Jurídica.

## Acesso

O acesso deve exigir nome de usuário e senha, mas **nenhuma senha real deve ser colocada no GitHub**.

Implementação recomendada:

- Cloudflare Access / Zero Trust para autenticação;
- Worker/API para autorização;
- secrets fora do repositório;
- arquivos privados em armazenamento protegido, quando necessário;
- logs mínimos de acesso.

## Regra

Projetos pessoais, arquivos sigilosos, dados de estudante, chaves, senhas ou materiais privados não devem ser publicados em repositório público.
